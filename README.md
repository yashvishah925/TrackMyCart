TrackMyCart
A Smart, Real-Time Grocery Budgeting Assistant

Overview
TrackMyCart is a Flutter-based mobile application designed to bridge the gap between shopping lists and actual expense tracking. It provides users with live feedback on their spending against a set monthly budget.

Key Features
Real-Time Firebase Sync: All grocery items and budget data are stored securely in Firebase Firestore.

Dynamic Budgeting: Automatically calculates Budget - Total Spent = Remaining Balance in real-time.

Categorized Lists: Items are organized by type (Vegetables, Fruits, etc.) for a faster shopping experience.

Visual Spending Alerts: Immediate UI feedback if spending exceeds the user-defined budget.

Technical Implementation
Frontend: Flutter (Dart)

Backend: Firebase Firestore & Authentication

Release: Optimized Android APK with custom branding
